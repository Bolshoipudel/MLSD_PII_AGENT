# Self-improving PII detection
Проект для курса ML System Design (ИТМО): локальный агент, который находит причины ошибок детектора персональных данных (ПД) в русскоязычных текстах и исправляет их прямо в работающем сервисе, без правки исходного кода.

## Идея

Перед тем как отправить текст в LLM, детектор находит и маскирует в нём персональные данные. Сейчас такие детекторы улучшает инженер вручную, разбирая логи пропусков и ложных срабатываний.

Гипотеза проекта: ошибки детектора собираются в группы — сценарий, шаблон фразы, формат записи, тип сущности. Тогда агент, который видит лог срабатываний, может найти эти группы и подобрать под каждую своё исправление:

- правило — где хватает правила;
- дообучение на подмножестве — где нужна модель;
- маршрутизацию в LLM — где не справляется ни то, ни другое.

Проверяем, получается ли так точнее и дешевле, чем полное дообучение NER-модели или чем использовать обычного кодингового агента.

## Что делаем

- **Бейзлайн:** regex + [GLiNER Guard](https://huggingface.co/hivetrace/gliner-guard-uniencoder).
- **Агент** на локальной LLM (не больше одной H100): анализ логов → кластеризация ошибок → гипотезы → исполнение в песочнице → замер → отчёт. Исправления — новые версии политики детектора (правила, списки, пороги, маршрутизация в LLM), код не меняется.
- **Сервис с фронтендом:** детектор ошибся → пользователь нажимает «Агент, помоги» → агент находит причину, проверяет исправление на golden set и применяет его в рантайме, не снижая recall и не ломая текущий инференс.
- **Сравнение** с полным дообучением и обычным кодовым агентом по качеству и стоимости инференса.
- **Честная оценка:** итоговое качество считаем на закрытом бенчмарке [PII-Bench](https://huggingface.co/datasets/hivetrace/pii-bench), который не видят ни агент, ни бейзлайны.

Подробно — в [дизайн-документе](docs/ml_system_design_doc.md).

## Как запустить у себя

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/). Подходящую версию Python (3.12 или новее) uv при необходимости скачает сам.

```bash
git clone https://github.com/Bolshoipudel/MLSD_PII_AGENT.git
cd MLSD_PII_AGENT
uv sync
uv run pre-commit install
```

Проверить весь репозиторий: `uv run pre-commit run --all-files`. Запустить линтер и форматтер вручную: `uv run ruff check .` и `uv run ruff format .`.
